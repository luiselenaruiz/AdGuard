\# Pràctica AdGuard Home



\## Objectiu

Desplegar AdGuard Home amb Docker Compose i utilitzar-lo com a DNS amb filtratge.



\## Tecnologies

\- Docker

\- Docker Compose

\- AdGuard Home



\## Desplegament



```bash

docker compose up -d
```
